# API de Gerenciamento de Pedidos

Projeto prático avaliativo desenvolvido para a disciplina de Tópicos Avançados em Sistemas de Informação II.

## 🚀 Tecnologias Utilizadas
- **Node.js** com **Express** (JavaScript)
- **Jest** e **Supertest** para testes automatizados
- **Postman** para testes manuais e evidências
- **Git** e **GitHub** para versionamento

## 🤖 Uso de Inteligência Artificial

De acordo com as diretrizes do projeto, informamos que a Inteligência Artificial foi utilizada como apoio ao longo do desenvolvimento das seguintes tarefas:   

Estruturação da Arquitetura em Camadas: Auxílio na divisão correta entre rotas, controladores e serviços.

Definição de Regras de Negócio: Elaboração das validações de transição de status e tratamento de erros HTTP.

Sugestão aceita com justificativa: A sugestão de utilizar classes separadas para serviços e controladores foi totalmente aceita porque promove uma organização limpa, desacoplada e de fácil manutenção para os testes automatizados com o Jest.
